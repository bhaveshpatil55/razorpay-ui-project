# Razorpay UI Project 💳

A responsive frontend clone of the Razorpay website built using **HTML and Tailwind CSS**.

## 🌐 Live Demo

[View Live Website](https://razorpay-ui-project.netlify.app/)

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* PostCSS

## ✨ Features

* Responsive and modern UI
* Razorpay-inspired landing page
* Responsive navigation bar
* Hero section
* Payment and business sections
* Feature sections
* Responsive footer
* Mobile-friendly design

## ▶️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/razorpay-ui-project.git
```

### 2. Open the project folder

```bash
cd razorpay-ui-project
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project

Use your configured Tailwind build command, or open `index.html` directly if the project is already using generated CSS.

This project was created to practice frontend development, responsive web design, and Tailwind CSS.
